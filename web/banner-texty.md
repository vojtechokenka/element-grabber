# Element Grabber: podklady pro banner na webu

## Obrázky

- `banner-light.webp` a `banner-dark.webp` (646 × 720 px, průhledné pozadí). Jsou ve dvojnásobném rozlišení pro zobrazení ve výšce 360 px, stejně jako `pivot-banner.webp`.
- Stejné soubory jsou i jako PNG.
- Světlá verze patří do světlého režimu webu, tmavá do tmavého (třídy `only-light` a `only-dark` jako u Mac appek).

Alt text:

```
The Element Grabber picker outlining a card on a page, with a note that the PNG was copied
```

## Texty, varianta jako u Pivotu (velký nadpis)

Štítek:

```
For Chrome Users
```

Nadpis:

```
I built a Chrome extension that copies any element as a PNG.
```

Text:

```
Element Grabber works like the inspector in DevTools, minus the DevTools. Press a shortcut, point at an element and click. It lands in your clipboard as a PNG, however tall it is. Hold Alt and you get its text instead.
```

Tlačítko:

```
Get the extension
```

## Texty, varianta jako u Mac appek (jedna věta)

```
I built a free, open-source Chrome extension that copies any element on a page as a PNG, or grabs its text.
```
